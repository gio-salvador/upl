# Vulnerability disclosure policy

## Where to report

Report privately through a GitHub Security Advisory:
<https://github.com/gio-salvador/upl/security/advisories/new>

Please do not open a public issue for a security problem.

## What to expect

- **Acknowledgement** within 5 working days
- **Coordinated disclosure** with the reporter; default 90-day window

This is a personal project maintained by one person, so timelines are best effort.

## In scope

- The published website built from `site/`
- This repository: CI/CD, dependencies, and supply chain

## Out of scope

- Third-party services such as GitHub and Cloudflare (report to the vendor)
- Social engineering and physical security
- Volumetric or network denial of service
- Disagreement with the teachings; open a normal issue for that

## Safe harbour

Good-faith research that avoids privacy violations, data destruction, and service disruption,
and that allows reasonable time before public disclosure, will not be pursued legally.

There is no paid bug-bounty programme. Contributions are credited with the reporter's consent.
