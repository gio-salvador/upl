# Agents

The Claude Code agents that belong to this repository, for the author and for contributors who
work on the teachings with Claude Code. Each page here describes the agent file of the same
name under `.claude/agents/`.

| Agent | Purpose |
| ----- | ------- |
| [upl-teaching-steward](upl-teaching-steward.md) | Reviews the teachings against the core beliefs, proposes improvements for the author to approve, and drafts new pages. |

Project-local agents, skills and rules carry the `upl-` prefix
([conventions.md](../conventions.md)).
